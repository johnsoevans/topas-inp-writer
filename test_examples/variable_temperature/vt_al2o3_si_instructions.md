1. It was synchrotron data with a wavelength of 0.8257653 Anstroms.
1. The cif files are in this directory.
1. The data files are in a folder call xye_files.  I downloaded them
1. The logbook containing the filenames and temperatures is below.

1. I'm going to want to look at the refinements afterwards in Reel.
1. Save the main input file and results in this folder.  Open the input file when it's made.
