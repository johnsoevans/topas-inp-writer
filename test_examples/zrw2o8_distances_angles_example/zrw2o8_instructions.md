## General instructions

## Specific instructions
1. Perform a Rietveld refinement. 
1. **Open the inp file as soon as created**
1. The data file is 6G17PB01.raw in the same directory as this md file. 
1. The cif file is zrw2o8_rt.cif.
1. Data were recorded on a Bruker diffractometer with Cu Ka1/Ka2 radiation and no monochromator.  Variable divergence slits were used.
1. Save all workings in a subdirectory called zrw2o8_workings.
1. **Before any Rietveld** set up bond distance and angle restraints such that Zr is octahedrally coordinated with 90/180 angles and with a bond length of 2.075 A and W is tetrahedrally coordinated with 109.5 degree angles and a bond length of 1.790 A.  
1. Check the Rietveld model against a Pawley model to judge the quality.  Make any adjustments needed to the Rietveld fit.
