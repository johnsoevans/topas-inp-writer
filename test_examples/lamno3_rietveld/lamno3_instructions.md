# LaMnO3 Rietveld refinement

## General instructions for example Rietvelds
1. Forget any previous work you've done on this example and start from scratch.
1. Use the minimum number of prompts this session, allow anything you can.
1. Don't look at other files on this computer which may have previous examples of the problem.
1. Don't look on the internet for specific earlier examples of this problem.

## Specific instructions for this refinement
1. The data is in lamno3.xy in the same directory as this md file. 
1. The cif file with a starting model is in LaMn03_pbmn_start.cif.
1. Data were recorded on a Bruker diffractometer with Cu Ka1/Ka2 radiation and no monochromator.  
1. Try using a TCHZ peak shape.
1. A template for a typical refinement is in the skills folder example_inp_files tio2_lab_bragg_brentano_rietveld.inp.
1. Store any files apart from the inp file in a folder lamno3_workings.
