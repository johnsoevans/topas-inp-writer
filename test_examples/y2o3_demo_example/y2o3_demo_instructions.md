# Y2O3 Rietveld refinement (from the demo example)

## General instructions for example Rietvelds
1. Forget any previous work you've done on this example and start from scratch.
1. Use the minimum number of prompts this session, allow anything you can.
1. Don't look at other files on this computer which may have previous examples of the problem.
1. Don't look on the internet for specific earlier examples of this problem.

## Specific instructions for this refinement
1. The data is in y2o3_demo.xye in the same directory as this md file. 
1. The cif file with a starting model is in y2o3_start.cif.
1. Data were recorded on a Bruker diffractometer with Cu Ka1 radiation and a Ge monochromator.  
1. Store any files apart from the inp file in a folder y2o3_workings.
1. Consider the background treatement carefully.
1. Check for preferred orientation.
1. Check for hkl-dependent peak shapes.
1. Check for any instrumental artifacts.
